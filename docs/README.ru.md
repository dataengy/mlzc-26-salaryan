# Предиктор зарплат в AI / Data — ML Zoomcamp 2026 Midterm

**Задача.** Оценивать ориентировочную годовую зарплату до налогов в USD по должности, уровню опыта, типу занятости, географии сотрудника и компании, доле удалённой работы и размеру компании. Результат — статистический ориентир по датасету, а не оффер, индивидуальная оценка или прогноз для B2B-рынка Грузии.

**Данные.** Global AI/ML/Data Science Salary Index от aijobs.net, лицензия CC0. `scripts/download.py` скачивает CSV, а `data/source.json` сохраняет URL, размер и SHA256.

## Результаты последнего проверенного запуска

После очистки осталось 71 890 строк; обучение использовало воспроизводимую выборку из 50 000 строк. Временное разделение: обучение — до 2023 года включительно, валидация — 2024 год, тест — 2025 год и позже. По MAE на валидации выбрана Ridge-регрессия (`alpha=1`): MAE $49 934,15, RMSE $71 760,75. На отложенном тесте: **MAE $47 217,81**, **RMSE $67 735,40**. MAE базовой медианной модели на валидации — $57 526,48. Полные сравнения находятся в [`models/metrics.json`](../models/metrics.json).

EDA включает распределение целевой переменной, пропуски, медианную зарплату по уровню опыта и permutation importance. Наибольший вклад в предсказание текущей Ridge-модели дают название должности, уровень опыта, страна проживания сотрудника и страна компании. Важность признаков зависит от модели и не доказывает причинную связь; коррелирующие признаки могут делить или маскировать важность. См. [отчёт EDA](../reports/EDA.md) и [график важности](../reports/feature_importance.png).

## Установка и запуск

Установите `uv`, затем из корня репозитория выполните (Python 3.12):

```bash
make setup
make data
make eda
make train
make test
```

`.envrc` добавляет `.venv/bin` в `PATH`. Если используется direnv, один раз выполните `direnv allow`. Без direnv запускайте Python как `.venv/bin/python` или пользуйтесь Make-целями.

Запуск API через `make serve`; в другом терминале проверьте:

```bash
curl -fsS http://localhost:8080/health
curl -fsS -X POST http://localhost:8080/predict \
  -H 'Content-Type: application/json' \
  -d @../data/examples/sample-request.json
```

## Docker

Обученная модель хранится в Git, поэтому образ можно собрать из чистого клона:

```bash
docker build -t mlzc-salary .
docker run --rm -p 8080:8080 mlzc-salary
```

`make docker-check` соберёт образ, запустит временный контейнер и проверит оба endpoint. CSV не входит в репозиторий; его загружает `make data`.

## Данные и моделирование

Признаки: `experience_level`, `employment_type`, `job_title`, `employee_residence`, `remote_ratio`, `company_location`, `company_size`. `salary`, `salary_currency` и `salary_in_usd` не передаются модели, чтобы избежать утечки целевой переменной. `work_year` используется только для разбиения данных. Если временные группы недостаточны, применяется детерминированное случайное разделение 60/20/20; факт записывается в JSON метрик.

`src/mlzc_26_salaryan/train.py` сравнивает медианный `DummyRegressor`, два значения регуляризации Ridge и две глубины Random Forest по MAE/RMSE на валидации. Победитель выбирается по MAE, переобучается на обучающей и валидационной выборках и один раз оценивается на тесте. Notebook [`notebooks/salary-prediction.ipynb`](../notebooks/salary-prediction.ipynb) описывает очистку, EDA, сравнение моделей и важность признаков. Подробности — в [индексе документации](README.md).

Исторический опрос может иметь смещения выборки, географии и времени; удаление точных дублей не выявляет повторных респондентов. Не используйте модель для решений о компенсации конкретным людям.
